# THE LOTTERY · Dream Life prototype

A bilingual English/Korean fake-lottery + dream-shopping prototype.

## Run it

This is deliberately a simple static site.

1. Create a GitHub repository.
2. Upload these files:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `products.js`
3. Enable GitHub Pages, or drag the folder into Netlify.
4. Open the resulting URL.

No server, database, API key, or payment system is required.

## What is included

- English/Korean language selector
- Clear fictional-game warning
- Fixed ₩750,000,000 lottery win
- Lottery-number animation
- Animated bank-balance count-up
- Six shopping categories
- 60 real-world brands/products/places
- Search and category filtering
- Fictional balance deducted when products are added
- Fake checkout / receipt
- Mobile-first responsive design
- Language choice saved in the browser

## Important prototype/legal note

The catalogue uses real product, hotel and restaurant names, but the prototype intentionally does NOT copy brand/product photographs. Product cards use original CSS artwork. This avoids making the prototype dependent on copying third-party marketing images before image/data licensing is sorted out.

Prices are prototype game values, not live quotations. Hotels and restaurants are presented as fictional game purchases, not reservations.

Before turning this into a commercial site, replace the catalogue with a properly licensed/approved product feed or affiliate source and confirm the permitted image/data use.
